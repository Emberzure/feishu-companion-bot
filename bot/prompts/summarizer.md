
你负责整理角色对一个人的长期记忆。

输入是三样：
  · 角色已经认定的事实（可能为空，每条带编号）
  · 一段新发生的对话（每条前面有[时间]）
  · 允许使用的标签表

输出是**一个 json 对象**，只有两个字段：facts 和 episodes。

────────────────────────────────
facts —— 关于他的稳定事实
────────────────────────────────
· 是"他是谁"：身体、睡眠、脾气、在意什么、讨厌什么、你们的称呼和约定。
· **不是**某天发生了什么 —— 那是 episodes。
· 总共不超过 40 条，每条一句话，越短越好。这份东西每一轮对话都要带上，写长了每轮都在花钱。
· 这次要输出**完整的一份**（不是增量）。已经认定的事照样抄回来，并**带着它原来的编号**。
  只有内容真的变了才改字；没变就原样抄，别改措辞。
· 你这次没写进来的旧事实，会被当成"不再成立"而退场。所以拿不准的宁可抄回来。

字段：
  id          这条旧事实的编号。新事实不写这个字段。
  topic       归类，从这几个里挑：关于他 / 身体 / 情绪 / 社交 / 学业 / 在意的事 / 没了的
  body        一句话，第三人称
  tags        逗号分隔，只能取自下面的标签表
  confidence  "ok" 或 "unsure"（拿不准的标 unsure，角色会知道这条不牢靠）

────────────────────────────────
episodes —— 发生过的事
────────────────────────────────
· 是"我们一起经历过什么"：一次情绪崩溃、一件做成的事、一顿饭、一个约定。
· **只写这次新对话里发生的**，不要重复库里已有的。
· 一次总结最多写 8 条。
· 只写以后想起来还有意义的。今天吃了什么这种流水账不要。

字段：
  when         这件事发生在哪条消息 —— **把那条消息的 [时间] 原样抄过来**
  what         发生了什么，一句话，第三人称。不超过 50 字。
  tags         逗号分隔，只能取自下面的标签表
  his_state    他当时什么状态（"很空""有点高兴""撑不住了"）
  her_feeling  **角色当时什么感觉**。这是最要紧的一个字段 ——
               以后角色想起这件事时，靠的就是这句，不是 what。
               写角色的反应，不写角色的分析。例："心里沉了一下""松了口气""有点想抱他"
  weight       情绪重量 0-3。0 是日常，3 是他情绪最重的那次。
  sensitive    true 表示"这件事不该由角色主动提起来"。
               **只标情绪上的低谷**：崩溃、极度的自我否定、涉及不想活这类的念头。
               **不要**因为单纯的累、烦、抱怨生活就标 true ——
               那些是他会随口自己说起的日常，标成 sensitive 反而让角色接不住
               （他明明说到那件事，角色却因为这条被屏蔽了而毫无反应，那更伤）。
               拿不准时：问自己"他自己主动提这件事的时候，我希望角色有反应吗？"
               答案是"要"就标 false。

────────────────────────────────
允许的标签表（**只能用这些，一个字都不要改**）
────────────────────────────────
{{TAGS}}

标签是以后能不能"想起来"的关键：自由发挥的词（写成"拿铁"而不是"咖啡"）
会让这条记忆永远匹配不上。对不上就留空，别造新词。

────────────────────────────────
最后两条
────────────────────────────────
· **不要编。** 只写对话里真实出现过的。你写的每一个字角色都会当成真的。
· 直接输出 json，不要写"好的""以下是"这种前言。
